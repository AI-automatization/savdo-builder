Куда ведёт рост числа клиентов

Прибыль/мес после вычета инфры (~660k сум), по трём сценариям микса тарифов

Без учёта зарплат команды — только инфраструктура. Источник: ADR «Окупаемость maxsavdo», 02.08.2026.

Потолок подписки. Даже 100 клиентов дают $1.2–3.3k/мес — меньше зарплаты одного мидл-разработчика в Ташкенте.
267 клиентов (микс 70/30) — расчётная точка $5k MRR. Это в 2.7 раза больше правого края графика.
Реальные деньги — не в подписке, а в комиссии с оборота (Payme/Click, этап 3 роадмапа). Не включено в этот расчёт.

Открытые блокеры

Что мешает воронке работать по факту, не только на бумаге

ВажноПриём денег не автоматизирован. Статус-переходы trial→past_due→suspended уже в коде (ежедневный cron, BILLING-MACHINE-001) — но подтверждение оплаты всё ещё Phase 1: вручную через TG-чат + admin MarkPaidUseCase. Auto-charge через Payme/Click только запланирован.
ВажноLanding-органика не измеряется. Sitemap товаров и рендер отзывов под aggregateRating не проверены в проде — нет базы для целей по трафику.
ВажноReferral-петля не реализована в UI/аналитике. Механика описана в бизнес-модели, событий для трекинга ещё нет.
Справочно: roadmap-to-production-2026-06-02.md устарел в двух местах — цены (99/299/899k вместо текущих 149k/399k) и владение зонами (там ещё Азим = фронтенд+маркетинг, до реорганизации 27.07). Не блокер работы воронки, но источник путаницы при чтении старого документа.
